CUDA를 사용하는 가장 큰 이유는 CPU의 sequential execution보다 빠른것을 보여야하는데 감으로 하는게 아닌 정확하게 측정하는 방법에 대해 알아보자.


방법 1. wall-clock time(elapsed real time)
컴퓨터 프로그램이 실행되면서 실제로 흘러가는 시간-> 이론상 벽시계로 측정 해도 같은 결과 

CPU time (CUDA에서는 GPU 타임)
컴퓨터 프로그램이 실행 중에 CPU를 사용한 시간->기본적으로 cpu는 time sharing을 하기에 실제로 내가 순수 사용하는 시간은 wall clock으로 측정한 것 보다 작다.
C++ 프로그램을 실행 한다고 하면 실제 내 프로그램이 돌아가는 시간(user time) + 프로그램이 실행되기위해 운영체제가 돌아가는 시간(system tiem)을 합쳐서 CPU time이라고 한다.
그러므로 일반적으로 CPU time < wall-clock time 이지만 이론상 병렬프로그래밍에서는 반대도가능 왜냐하면
wall-clock 시간이 1초이지만 코어가 3개 작동한경우 1초동안 3초의 일을으해서 이론적이지 잘일어나지는 않는다.

하지만 시간을 따질 때는 wall-clock 타임을 사용한다. 왜냐하면 cpu 타임을 사용하면 작성한 프로그램이 돌다가 어떤 메모리에 접근하거나 혹은 하드디스크에 접근할때는 cpu가 안돌아가서
cpu 타임에 포함이 안된다. 그래서 실제 프로그램이 돌아가는 시간과 거리가 있기에 

C++에 #include<chrono>를 이용한다 -> Wall-clock time!

typedef duration<long long> seconds;
typdef duration<long long, milli> milliseconds;

{
    system_clock::time_point chrono_begin = system_clock::now(); //current time
    clock_t clock_begin = clock();
    double S0 = 100.0;      // 현재 주가
    double K = 100.0;       // 행사가격
    double r = 0.05;        // 무위험 이자율
    double sigma = 0.2;     // 변동성
    double T = 1.0;         // 만기까지 시간, 1년

    int numSimulations = 1e8; // 시뮬레이션 횟수

    random_device rd;
    mt19937 gen(rd());
    normal_distribution<double> normalDist(0.0, 1.0);

    double payoffSum = 0.0;

    for (int i = 0; i < numSimulations; i++)
    {
        double Z = normalDist(gen);
        double ST = S0 * exp((r - 0.5 * sigma * sigma) * T + sigma * sqrt(T) * Z);
        double payoff = max(ST - K, 0.0);
        payoffSum += payoff;
    }
    double callPrice = exp(-r * T) * (payoffSum / numSimulations);

    clock_t clock_end = clock();
    double clock_elapsed_milli = 1000.0 * (clock_end - clock_begin) / CLOCKS_PER_SEC;
    cout << "elapsed CPU time: " << clock_elapsed_milli << " ms" << endl;

    system_clock::time_point chrono_end = system_clock::now(); //end time
    milliseconds elapsed_millisec = duration_cast<milliseconds>(chrono_end - chrono_begin);
    cout << "elapsed time: " << elapsed_millisec.count() << " ms" << endl;
    cout << "European Call Option Price: " << callPrice << endl;

    return 0;
}
