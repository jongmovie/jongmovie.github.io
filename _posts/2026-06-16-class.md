# 객체
C++ 객체를 설명하기에 앞서 우선 클래스(class)라는 개념을 먼저 설명한다.
클래스란 객체를 정의하는 틀 또는 설계도로서, 클래스에는 멤버 변수와 멤버 함수를 선언한다.
즉, C++ 객체는 C++ 클래스라는 틀에서 찍어내며 멤버 변수 메모리와 멤버 함수 코드를 실제 가지고 
C++ 프로그램이 실행되는 동안 실존하느 인스턴스이다.

# 클래스 만들기
클래스는 일반적으로 클래스 선언부와 클래스 구현부로 나누어 작성된다. 

클래스는 class 키워드와 클래스 이름으로 선언한다.

클래스 선언부는 멤버 변수, 멤버 함수가있고 각 멤버의 접근을 어느정도로 할 수 있는지 지정해주는 접근지정자(public, private, protected)가 있다.

클래스 구현부에는 클래스내에 멤버 함수를 구현한다.

다음은 유럽형 콜옵션 class를만드는 예제이다. 

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

class Option
{
public:
    double S = 100.0;
    double K = 100.0;

    double payoff();
};

double Option::payoff()
{
    return max(S - K, 0.0);
}
```
