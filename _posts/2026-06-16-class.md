# 클래스와 객체

C++에서 객체를 이해하려면 먼저 **클래스(class)** 라는 개념을 알아야 한다.

클래스는 객체를 만들기 위한 **틀** 또는 **설계도**이다.
클래스 안에는 객체가 가지게 될 **데이터**와 **기능**을 정의한다.

C++에서는 클래스 안에 선언된 데이터를 **멤버 변수(member variable)**,
클래스 안에 선언된 기능을 **멤버 함수(member function)** 라고 부른다.

예를 들어 옵션 상품을 코드로 표현한다고 생각해보자.
옵션의 기초자산 가격 `S`, 행사가격 `K`는 데이터이므로 **멤버 변수**가 될 수 있다.
그리고 옵션의 페이오프를 계산하는 `payoff()`는 기능이므로 **멤버 함수**가 될 수 있다.

이번 글에서는 **유럽형 콜옵션(European Call Option)** 을 예제로 사용하여 C++의 클래스와 객체를 살펴본다.

---

## 1. 클래스란 무엇인가?

클래스는 객체를 만들기 위한 **사용자 정의 자료형**이다.

기본 자료형인 `int`, `double`처럼 C++에서 미리 제공하는 자료형도 있지만,
프로그래머가 직접 새로운 자료형을 만들 수도 있다. 이때 사용하는 문법이 바로 `class`이다.

예를 들어 다음과 같이 `Option`이라는 클래스를 만들 수 있다.

```cpp
class Option
{
public:
    double S;
    double K;

    double payoff();
};
```

위 코드에서 `Option`은 클래스 이름이다.
이 클래스는 옵션 상품을 표현하기 위한 설계도라고 볼 수 있다.

`Option` 클래스 안에는 다음과 같은 멤버들이 있다.

* `S`: 기초자산 가격
* `K`: 행사가격
* `payoff()`: 콜옵션의 페이오프를 계산하는 함수

즉, 클래스는 객체가 가져야 할 **속성**과 **동작**을 미리 정의해두는 틀이다.

---

## 2. 객체란 무엇인가?

객체는 클래스를 바탕으로 실제 메모리에 생성된 **실체(instance)** 이다.

클래스가 설계도라면, 객체는 그 설계도를 바탕으로 실제로 만들어진 결과물이라고 볼 수 있다.

예를 들어 다음 코드는 `Option` 클래스 타입의 객체 `call`을 생성한다.

```cpp
Option call;
```

이 코드는 `int number;`와 비슷하게 이해할 수 있다.

```cpp
int number;
Option call;
```

`int number;`가 `int`형 변수 `number`를 만드는 것처럼,
`Option call;`은 `Option`형 객체 `call`을 만드는 코드이다.

객체가 생성되면 객체 안의 **멤버 변수**를 저장할 메모리 공간이 할당된다.
다만, **멤버 함수의 코드는 객체마다 따로 복사되어 저장되지 않는다.**
멤버 함수는 프로그램의 코드 영역에 존재하고, 여러 객체가 공통으로 사용한다.

따라서 객체가 실제로 가지는 데이터는 주로 **멤버 변수**라고 이해하면 된다.

---

# 유럽형 콜옵션 클래스 만들기

## 1. 클래스 선언부

클래스는 `class` 키워드와 **클래스 이름**을 사용해 선언한다.

```cpp
class Option
{
};
```

위 코드에서 `Option`은 클래스 이름이다.
여기서는 옵션 상품을 표현하기 위해 `Option`이라는 이름의 클래스를 만든다.

클래스 선언부에는 일반적으로 다음과 같은 요소들이 들어간다.

* **멤버 변수**: 클래스가 가지고 있는 데이터
* **멤버 함수**: 클래스가 수행할 수 있는 동작
* **접근 지정자**: 멤버에 접근할 수 있는 범위를 지정

이번 예제에서는 다음과 같이 `Option` 클래스를 선언한다.

```cpp
class Option
{
public:
    double S;
    double K;

    double payoff();
};
```

위 코드에서 `S`와 `K`는 **멤버 변수**이다.

```cpp
double S;
double K;
```

`S`는 기초자산 가격을 의미하고,
`K`는 행사가격을 의미한다.

그리고 `payoff()`는 **멤버 함수**이다.

```cpp
double payoff();
```

이 함수는 콜옵션의 페이오프를 계산하여 `double` 타입의 값을 반환한다.

---

## 2. 접근 지정자

클래스 내부의 멤버들은 **접근 지정자(access specifier)** 를 통해 외부에서 접근할 수 있는 범위가 결정된다.

C++ 클래스에서 자주 사용하는 접근 지정자는 다음 세 가지이다.

* `public`
* `private`
* `protected`

### `public`

`public`으로 선언된 멤버는 클래스 외부에서도 접근할 수 있다.

```cpp
public:
    double S;
    double K;
```

위 코드에서 `S`와 `K`는 `public` 영역에 있으므로 클래스 외부에서 직접 접근할 수 있다.

예를 들어 다음과 같이 객체를 통해 `S`의 값을 변경할 수 있다.

```cpp
call.S = 100;
```

### `private`

`private`으로 선언된 멤버는 클래스 외부에서 직접 접근할 수 없다.

또한 C++ 클래스에서는 접근 지정자를 따로 작성하지 않으면 기본값이 `private`이다.
따라서 클래스 외부에서 `S`에 직접 접근하려고 하면 오류가 발생한다.

### `protected`

`protected`는 상속 관계에서 사용되는 접근 지정자이다.
상속에 대한 내용은 이후에 따로 학습한다.

이번 예제에서는 객체 밖에서 `S`, `K`, `payoff()`에 접근할 수 있도록 `public`을 사용한다.

---

## 3. 클래스 구현부

클래스 선언부에서는 멤버 함수의 형태만 선언하고, 실제 동작은 클래스 외부에서 구현할 수 있다.

예를 들어 `payoff()` 함수는 클래스 선언부에서 다음과 같이 선언했다.

```cpp
double payoff();
```

이제 이 함수가 실제로 어떤 동작을 할지 구현해야 한다.

```cpp
double Option::payoff()
{
    return max(S - K, 0.0);
}
```

여기서 중요한 문법은 다음 부분이다.

```cpp
double Option::payoff()
```

`double Option::payoff()`에서 `double`은 **리턴 타입**, `Option`은 **클래스 이름**, `::`는 **범위 지정 연산자**, `payoff`는 **멤버 함수명**, `()`는 **매개 변수 부분**이다.

즉, 클래스 외부에서 멤버 함수를 구현할 때는 다음 형식을 사용한다.

```cpp
리턴타입 클래스이름::멤버함수명(매개변수)
```

이번 예제에서는 다음과 같이 해석할 수 있다.

* `double`: 함수가 `double` 타입의 값을 반환한다는 의미
* `Option`: `Option` 클래스에 속한 함수라는 의미
* `::`: 특정 클래스에 속한 멤버임을 나타내는 범위 지정 연산자
* `payoff`: 구현하려는 멤버 함수의 이름
* `()`: 매개 변수가 없다는 의미

따라서 `double Option::payoff()`는
**Option 클래스에 속한 payoff 함수이며, double 타입의 값을 반환하고, 매개 변수는 없는 함수**라고 해석할 수 있다.

## 4. 전체 코드

위 내용을 바탕으로 작성한 `Option` 클래스의 전체 코드는 다음과 같다.

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

class Option
{
public:
    double S;
    double K;

    double payoff();
};

double Option::payoff()
{
    return max(S - K, 0.0);
}
```

이 코드에서는 `Option` 클래스를 만들고,
그 안에 기초자산 가격 `S`, 행사가격 `K`, 그리고 페이오프를 계산하는 `payoff()` 함수를 정의했다.

아직 객체를 생성하지 않았기 때문에 실제 계산은 수행되지 않는다.
클래스는 어디까지나 객체를 만들기 위한 **설계도**이다.

# 객체 생성

이제 앞에서 만든 `Option` 클래스를 이용해 실제 객체를 생성해보자.

객체는 클래스의 구조와 기능을 실제로 사용할 수 있게 만들어진 실체이다.
즉, `Option`이라는 설계도를 이용해 `call`이라는 객체를 만드는 것이다.

```cpp
Option call;
```

위 코드는 `Option` 클래스 타입의 객체 `call`을 생성한다.

---

## 1. 객체와 메모리

변수를 선언하면 메모리에 해당 변수의 공간이 할당된다.
마찬가지로 객체를 생성하면, 그 객체가 가지고 있는 **멤버 변수의 크기만큼 메모리 공간**이 할당된다.

현재 `Option` 클래스에는 다음 두 개의 멤버 변수가 있다.

```cpp
double S = 100.0;
double K = 100.0;
```

`double` 타입은 일반적으로 **8 bytes**를 차지한다.
따라서 `Option` 클래스의 객체인 `call`은 보통 다음과 같은 크기를 가진다.

```text
S : double → 8 bytes
K : double → 8 bytes
---------------------
총 크기      16 bytes
```

즉, `call` 객체는 일반적으로 **16 bytes**의 메모리를 차지한다.

객체의 크기는 `sizeof` 연산자를 사용해 직접 확인할 수 있다.

```cpp
cout << sizeof(call) << endl;
```

여기서 다시 한 번 주의할 점은 **멤버 함수는 객체마다 따로 저장되지 않는다**는 것이다.

객체 안에 저장되는 것은 주로 `S`, `K`와 같은 **멤버 변수**이다.
`payoff()` 같은 멤버 함수의 코드는 객체마다 복사되지 않고, 여러 객체가 공통으로 사용한다.

---

## 2. 객체의 멤버에 접근하기

객체가 자신의 멤버 변수나 멤버 함수에 접근할 때는 **점 연산자 `.`** 를 사용한다.

형식은 다음과 같다.

```cpp
객체이름.멤버변수
객체이름.멤버함수()
```

예를 들어 `call` 객체의 멤버 변수 `S`에 값을 대입하려면 다음과 같이 작성한다.

```cpp
call.S = 100;
```

위 코드는 `call` 객체 안에 있는 `S` 값을 `100`으로 변경한다.

멤버 함수 `payoff()`를 호출하려면 다음과 같이 작성한다.

```cpp
double payoff = call.payoff();
```

위 코드는 `call` 객체의 `payoff()` 함수를 호출한 뒤,
그 결과를 `payoff`라는 변수에 저장한다.

즉, `call.payoff()`는 `call` 객체가 가지고 있는 `S`, `K` 값을 이용해 콜옵션의 페이오프를 계산하는 함수 호출이다.

---

## 3. 전체 코드

아래 코드는 `Option` 객체를 생성하고, 객체의 크기를 확인한 뒤, 콜옵션의 페이오프를 계산하는 예제이다.

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

class Option
{
public:
    double S;
    double K;

    double payoff();
};

double Option::payoff()
{
    return max(S - K, 0.0);
}

int main()
{
    Option call;

    cout << "객체 크기: " << sizeof(call) << " bytes" << endl;

    call.S = 100;
    call.K = 80;
    double payoff = call.payoff();

    cout << "payoff: " << payoff << endl;
}
```

코드 흐름을 정리하면 다음과 같다.

```cpp
Option call;
```

`Option` 클래스 타입의 객체 `call`을 생성한다.

```cpp
cout << "객체 크기: " << sizeof(call) << " bytes" << endl;
```

`sizeof(call)`을 이용해 `call` 객체가 차지하는 메모리 크기를 출력한다.

```cpp
call.S = 100;
```

`call` 객체의 멤버 변수 `S`에 `100`을 대입한다.

```cpp
call.K = 80;
```

`call` 객체의 멤버 변수 `K`에 `80`을 대입한다.

```cpp
double payoff = call.payoff();
```

`call` 객체의 멤버 함수 `payoff()`를 호출하고, 계산 결과를 `payoff` 변수에 저장한다.

```cpp
cout << "payoff: " << payoff << endl;
```

계산된 페이오프를 출력한다.

---

## 4. 실행 결과

위 코드의 실행 결과는 일반적으로 다음과 같다.

```text
객체 크기: 16 bytes
payoff: 20
```

먼저 `call` 객체의 크기는 보통 `16 bytes`이다.

그 이유는 `Option` 클래스 안에 `double` 타입 멤버 변수 `S`, `K`가 있기 때문이다.

```text
double S → 8 bytes
double K → 8 bytes
```

따라서 전체 크기는 일반적으로 다음과 같다.

```text
8 bytes + 8 bytes = 16 bytes
```

다음으로 페이오프 계산 과정을 살펴보자.

현재 `call.S`의 값은 `100.0`이고, `K`의 값은 `80.0`이다.

그러므로 결과는 `20`이 된다.

---

## 5. 정리

이번 예제에서는 C++의 **클래스**와 **객체**를 유럽형 콜옵션 예제를 통해 살펴보았다.

핵심 내용을 정리하면 다음과 같다.

* **클래스**는 객체를 만들기 위한 틀 또는 설계도이다.
* 클래스 안에는 **멤버 변수**와 **멤버 함수**를 선언할 수 있다.
* **객체**는 클래스를 바탕으로 실제 메모리에 생성된 실체이다.
* `Option call;`은 `Option` 클래스 타입의 객체 `call`을 생성하는 코드이다.
* 객체의 멤버에 접근할 때는 점 연산자 `.`를 사용한다.
* `call.S`는 멤버 변수 접근이고, `call.payoff()`는 멤버 함수 호출이다.
* 객체가 실제로 저장하는 데이터는 주로 멤버 변수이다.
* 멤버 함수는 객체마다 따로 저장되지 않고, 여러 객체가 공통으로 사용한다.
* `S`, `K`는 각각 `double` 타입이므로 `call` 객체의 크기는 일반적으로 `16 bytes`이다.

결국 클래스와 객체의 관계는 다음과 같이 정리할 수 있다.

```text
클래스 = 객체를 만들기 위한 설계도
객체   = 클래스를 바탕으로 실제 생성된 실체
```

이번 글에서 만든 `Option` 클래스는 콜옵션의 기초자산 가격 `S`, 행사가격 `K`, 페이오프 계산 함수 `payoff()`를 하나로 묶어 표현한 예제이다.
이를 통해 C++에서 클래스가 데이터를 저장하는 변수와 기능을 수행하는 함수를 하나의 단위로 묶는 문법이라는 점을 확인할 수 있다.
